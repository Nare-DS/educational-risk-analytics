# Privacy and Confidentiality

This repository is a public reconstruction of a project originally developed with sensitive educational data.

The following are intentionally excluded:

- raw student records
- original student/person IDs
- school/institution identifiers and names
- exact geographic locations
- private socioeconomic microdata
- private Google Drive links and local paths
- original notebook outputs containing raw records
- source datasets supplied for the academic project

All public records, IDs, regions and activity values are generated synthetically inside the notebook.

The public notebook preserves analytical methodology and documented decision logic, but does not reproduce real individuals or institutions.
